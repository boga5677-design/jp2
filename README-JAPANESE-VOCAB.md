# Nihongo Go - 日文單字庫版

此版本由 PetLingo v6.4.6 程式架構轉換，先保留原本 UI/美工，重點改為日文學習內容。

- 日文單字庫：259 筆
- 欄位：日文、中文、詞性、假名/羅馬字、JLPT 級別、分類、組別
- 支援搜尋：日文、中文、假名、羅馬字、分類
- 日語 TTS：Locale.JAPAN
- 聽力練習改為日文
- 口說辨識改為 ja-JP
- 單字測驗改為「日文→中文 / 中文→日文」
- 實用語句改為日文生活/旅行常用句
- GitHub Actions 更新為 setup-java@v5

美工圖片與整體 Compose 版型暫時保留，供下一階段再更新。
